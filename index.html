01 TitanEngine_Singularity.exe — Controls & Hotkeys
2M Particles Vortex

TitanEngine_Singularity.exe runs a real-time simulation of 2,000,000 meshlet particles spiraling into a relativistic Kerr Black Hole accretion disk. Evaluators can inspect the vortex using full 6-DOF flycam navigation from any angle.

Keyboard & Mouse Controls
Input Control Action Description
W A S D 6-DOF Flycam Flight Fly forward (W), backward (S), and strafe left/right (A/D).
Q / E Elevation Control Fly down (Q) or fly up (E) vertically.
Left Shift Turbo Speed Boost Hold to boost flight speed by 3x (400 → 1200 units/s).
Right Mouse Drag 360° Free Look Hold right mouse button and drag to look around seamlessly.
C Toggle Cinematic Auto-Orbit Enables automatic 360° circular camera orbit around the black hole.
H Toggle On-Screen HUD Hides or shows the transparent telemetry and controls overlay.
P Pause / Resume Simulation Freezes all particles in space; press again to resume real-time physics.
Particle Density Presets (Live Switching)
Hotkey Particle Count Showcase Purpose
F1 250,000 Particles Lightweight high-speed mode for ultra-high framerates (>140 FPS).
F2 500,000 Particles Balanced high-density accretion disk with clear orbital streamlines.
F3 1,000,000 Particles Cinematic baseline density showcasing full 3D cyclone funnel and disk.
F4 2,000,000 Particles Maximum hardware particle stress test across GPU silicon VRAM.
Holographic Transparent HUD
The HUD overlay is 100% transparent. No dark boxes obstruct the black hole vortex. Live stats (FPS, active particle count, singularity mass, event horizon radius) float directly over the 3D space particles. Press H anytime for clean fullscreen viewing.

02 TitanEngine_Prototype.exe — Controls & Scenes
15K Rigid Bodies

TitanEngine_Prototype.exe demonstrates high-performance rigid body physics simulation with up to 15,000 interacting bodies, multiple interactive stress scenes, kinetic collisions, and zero-jitter resting stacks.

Scene Selection Hotkeys
Key Scene Name Description & Behavior
1 Container Yard High-altitude drop of shipping containers testing high-velocity impact.
2 50-Layer Pyramid Multi-layer pyramid stack demonstrating zero-jitter rest equilibrium.
3 Kinetic Avalanche Massive stream of bodies sliding and tumbling down an inclined slope.
4 Destructible Towers Multi-column skyscraper towers ready to be shattered by impacts.
Interactive Controls & Experiments
Input Hotkey Action Description
SPACE Launch Kinetic Cannonball Fires a high-velocity heavy projectile directly into the scene.
G Toggle Gravity (Zero-G) Disables gravity to let bodies float, then re-enables to watch them settle.
C Velocity Heatmap Mode Color-codes bodies from blue (slow/resting) to bright yellow/red (fast).
R Instant Scene Reset Resets all objects to their initial positions immediately.
P Pause Physics Time Step Freezes physics simulation step; press again to resume.
H Toggle Telemetry HUD Toggles visibility of the diagnostic telemetry overlay.
ESC Exit Application Performs a clean shutdown and closes the viewport window.

03 Quick Start & Hardware Reference
User Guide
How to Run the Applications
Direct Standalone Launch (Zero Dependencies)
Both TitanEngine_Singularity.exe and TitanEngine_Prototype.exe are fully self-contained standalone binaries. Simply double-click either file to launch. No command prompt, Cargo, or external runtime installations are needed.
